# Instructions on how to reset a RP2040 / RP2350 board
Follow these instructions if your board ends up in an odd state

1. Download the reset firmware from [flash_nuke.uf2](https://datasheets.raspberrypi.com/soft/flash_nuke.uf2)
2. While holding the BOOTSEL / BOOT button on the RP2040 / RP2350 board, plug in the USB cable to your computer.
3. When the RPI-RP2 drive shows up on your computer, copy the flash_nuke.uf2 file to the RP2040 / RP2350 board
4. After the device reboots, follow the Install instructions [here](https://github.com/21-0075-disha/pico-ducky-remastered-shrike-lite/blob/main/README.md)
